# Implementation Plan: Zero Model Verification in Translation Hot Path & Concurrency Deduplication

**Branch**: `036-hot-path-model-verification` | **Date**: 2026-08-20 | **Spec**: [`specs/036-hot-path-model-verification/spec.md`](file:///e:/tailieuhoctap/laptrinhnangcao/th/merged/specs/036-hot-path-model-verification/spec.md)

---

## Summary

Audit and eliminate all outbound model verification network calls from the translation hot path (`validateModelMiddleware` $\to$ `/translate-raw`, `/polish-translation`, etc.), enforcing purely in-memory cache/preset lookups with immediate 400 rejection on cache misses. Implement Single-Flight Promise Deduplication (`inFlightVerifications`) in `modelInfoService` so $N$ concurrent verification calls for the same model ID trigger exactly 1 outbound Google API fetch.

## Phase 2: Implementation Steps (High-Level)

1. **Step 1 (`server/services/modelInfoService.ts`)**:
   - Add `private inFlightVerifications = new Map<string, Promise<ModelDefinition>>()`.
   - Add `public isModelVerifiedCached(modelId: string): boolean` (checks Presets and `verifiedModelsCache` only).
   - In `isModelVerified(modelId, apiKeys, allowProbe = false)`: Default `allowProbe` to `false` or separate cached vs explicit probe.
   - In `verifySingleModel(modelId, apiKey, customLabel)`: Check `inFlightVerifications` before fetching; store in flight promise and delete in `finally`.
2. **Step 2 (`server/routes/api.ts`)**:
   - Refactor `validateModelMiddleware` to call `modelInfoService.isModelVerifiedCached(model)`.
   - If false, return HTTP 400 `code: 'MODEL_UNVERIFIED'` immediately without any outbound network calls.
3. **Step 3 (Unit & Integration Tests)**:
   - In `server/services/__tests__/modelInfoService.test.ts`:
     - Test concurrent verification (20 concurrent calls $\to$ 1 fetch).
     - Test verification failure handling with cleanup.
     - Test cache hit, miss, stale, and refresh.
   - In `server/services/__tests__/modelValidation.test.ts`:
     - Test that `validateModelMiddleware` executes with 0 `fetch` calls in hot path.
4. **Step 4 (Quality Gates)**:
   - Run `npm run lint`, `npm test`, `npm run build`.

## Summary

Khắc phục triệt để lỗi HTTP 404 khi cộng tác viên mở dự án chia sẻ qua Google Picker bằng cách bổ sung `.setAppId(appId)` (Google Cloud Project Number) vào cả hai PickerBuilder trong `googlePickerService.ts`, thêm hỗ trợ cấu hình `VITE_GOOGLE_APP_ID` / localStorage / UI nâng cao, thực hiện validate trước danh sách `selectedFiles` trong `importProjectFromSharedFolder` để báo lỗi tập trung khi thiếu file, và cập nhật tài liệu hướng dẫn cấu hình trong `.env.example` và `README.md`.

## Proposed Technical Implementation Phases

### Phase 1: Google Picker Service Core & App ID Binding
1. **`googlePickerService.ts`**:
   - Add `getAppId()`, `setAppId()`, and `getCustomAppId()`.
   - In `openFolderPicker`: validate `appId` presence and call `builder.setAppId(appId)`.
   - In `openFilePicker`: validate `appId` presence and call `builder.setAppId(appId)`.

### Phase 2: Pre-Download Permission Validation
1. **`driveGranularSync.ts`**:
   - Implement `validateSelectedFilesForImport`.
   - In `importProjectFromSharedFolder`: validate `selectedFiles` against `project.json` and `manifest.json` before downloading chapter files.
   - Throw consolidated error if files are missing.

### Phase 3: UI & Advanced Configuration Integration
1. **`GoogleSyncAdvancedConfig.tsx` & `GoogleSyncModal.tsx`**:
   - Add `appIdInput`, `setAppIdInput`, `onSaveAppId`, `onResetAppId`, `isCustomAppId`, `revealAppId` props and JSX controls.
   - Wire state and localStorage persistence in `GoogleSyncModal.tsx`.

### Phase 4: Documentation & Quality Gates
1. Update `.env.example` and `README.md`.
2. Add unit tests for `getAppId`/`setAppId` and validation in `src/services/__tests__/googleDriveSyncService.test.ts`.
3. Run `npm run lint`, `npm test`, and `npm run build`.

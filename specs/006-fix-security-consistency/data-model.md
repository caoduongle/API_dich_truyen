# Data Model & Conceptual Entities: Fix Security Consistency

**Feature**: `006-fix-security-consistency`  
**Date**: 2026-08-19  

## 1. Aggregated Error Exception Entity (`ALL_KEYS_EXHAUSTED`)

### Representation
An `Error` instance thrown by `generateWithRotation` when all API keys fail.

### Structure & Sanitization Rules
| Property | Type | Description & Security Invariant |
|:---|:---|:---|
| `name` | `string` | `"Error"` |
| `message` | `string` | Template: `ALL_KEYS_EXHAUSTED: Đã thử toàn bộ {count} khóa API đều thất bại. Lỗi cuối: {redactedErrorText}` |
| `redactedErrorText` | `string` | Extracted from `lastError?.message || lastError` and sanitized by `redactApiKey(..., keysToTry)`. Must NOT contain any raw API key string. |

## 2. Controller Structured Log Entry Entity

### Representation
Structured logging event dispatched from controller handlers to stdout/stderr.

### Structure & Sanitization Rules
| Field | Type | Transformation Rule |
|:---|:---|:---|
| `timestamp` | `string` (ISO-8601) | Auto-generated by `Logger.formatMessage` |
| `level` | `'debug' \| 'info' \| 'warn' \| 'error'` | Mapped from controller calls (`logger.info`, `logger.warn`, `logger.error`) |
| `context` | `string` | Controller context name (e.g. `'RawTranslation'`, `'PolishTranslation'`, `'Glossary'`, `'AuthController'`) |
| `message` | `string` | Sanitized by `sanitizeSecretString` (strips `AIzaSy...`, `token=...`, `apiKey=...`, `Bearer ...`) |
| `meta` | `any` (Optional) | Deeply sanitized by `sanitizeValue` (redacts keys with sensitive names or values) |

## 3. Exact Public Path Whitelist Entity

### Representation
A `Set<string>` containing exact URL path strings permitted to bypass authentication.

### Whitelist Set Definition
```typescript
const PUBLIC_API_PATHS = new Set<string>([
  "/auth/login",
  "/auth/status",
  "/health",
  "/api/auth/login",
  "/api/auth/status",
  "/api/health",
]);
```

### Access Control Rules
- **Rule 1**: If `authStore.isAuthRequired()` is `false`, allow all requests.
- **Rule 2**: If `PUBLIC_API_PATHS.has(req.path || req.originalUrl || "")` is `true`, allow request (`next()`).
- **Rule 3**: Any other path (including paths with suffixes matching `/auth/login`, `/health`, etc.) MUST provide a valid auth token or be rejected with HTTP 401.

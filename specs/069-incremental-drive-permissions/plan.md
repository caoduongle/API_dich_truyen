# Implementation Plan: Incremental Drive Permissions for Shared Project Files

**Branch**: `069-incremental-drive-permissions` | **Date**: 2026-08-23 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/069-incremental-drive-permissions/spec.md`

## Summary

Bổ sung cơ chế Google Picker chọn-nhiều-file (multi-select) neo vào `driveFolderId` đã biết trong `src/services/googlePickerService.ts` để cộng tác viên chủ động cấp quyền `drive.file` cho các tệp trong thư mục chia sẻ. Tích hợp trực tiếp vào luồng "Mở dự án được chia sẻ" lần đầu (sửa triệt để lỗi không tìm thấy `project.json`) và thêm nút "Đồng bộ file mới" độc lập trong `ShareProjectModal.tsx`/`GoogleSyncModal.tsx`. Đồng thời, cách ly lỗi tải từng chương trong `driveGranularSync.ts` để đảm bảo quá trình đồng bộ 2 chiều không bị hỏng khi có file mới chưa cấp quyền.

## Proposed Technical Implementation Phases

### Phase 1: Service Layer Extensions
1. **`googlePickerService.ts`**:
   - Implement `openFilePicker(options: OpenFilePickerOptions)` configuring `DocsView(ViewId.DOCS).setParent(folderId)` with `MULTISELECT_ENABLED`.
2. **`driveGranularSync.ts`**:
   - Update `importProjectFromSharedFolder` to accept optional `selectedFiles` parameter, resolving `project.json` and chapter IDs directly.
   - Wrap chapter download loop in `syncGranularProject` with `try / catch`, tracking `failedPullCount` and skipping failing files without breaking the sync loop.
3. **`googleDriveSyncService.ts`**:
   - Export helper `syncGranularProjectFiles(token, projectId, folderId, onProgress)` for the "Đồng bộ file mới" action.

### Phase 2: UI Layer Integration
1. **`GoogleSyncModal.tsx`**:
   - Update `handleOpenSharedProjectPicker`: after folder selection, automatically open `openFilePicker` for that folder, then call `importProjectFromSharedFolder`.
   - Update `handleBiDirectionalSync`: surface detailed notification if `failedPullCount > 0`, advising user to click "Đồng bộ file mới".
2. **`ShareProjectModal.tsx`**:
   - Add a "Đồng bộ file mới" card/button for granular projects (`driveStorageFormat === 'granular'`), allowing collaborators to re-open the file picker and pull new chapters in one step.

### Phase 3: Unit Tests & Verification
1. Add tests in `src/services/__tests__/googleDriveSyncService.test.ts` and `granularSyncReconciliation.test.ts` to verify per-chapter error isolation and summary counting.
2. Run `npm run lint`, `npm test`, and `npm run build`.

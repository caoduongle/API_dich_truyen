# Implementation Plan: Fix Single-File Bundle Sharing Wiring & Permission Scoping

**Branch**: `074-fix-bundle-share-wiring` | **Date**: 2026-08-24 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/074-fix-bundle-share-wiring/spec.md`

## Summary

Fix the sharing initialization wiring in `ShareProjectModal.tsx` so newly shared projects migrate directly to the single-file bundle architecture (`migrateOwnerProjectToBundle()`), replacing the deprecated multi-file granular subfolder approach. Generalize `googleDrivePermissionsService.ts` to manage access rights scoped strictly to individual resource IDs (`driveFileId` for bundles, `driveFolderId` for legacy granular projects), preventing parent application folder privacy leaks. Provide an explicit manual upgrade path for legacy granular projects and update task documentation for Spec 072.

## Proposed Changes Summary

### 1. `src/services/googleDrivePermissionsService.ts`
- Generalize `folderId` parameter to `resourceId` in `shareFolderWithUser`, `listFolderCollaborators`, and `revokeFolderPermission`.
- Update JSDoc comments to document that `resourceId` can be either a Google Drive File ID or Folder ID.

### 2. `src/components/google-sync/ShareProjectModal.tsx`
- Implement 3-state logic:
  - **State A (Unshared)**: Button calls `googleDriveSyncService.migrateOwnerProjectToBundle(token, project.id, setMigrationProgress)`.
  - **State B (Legacy Granular)**: Manages collaborators via `project.driveFolderId`; offers explicit "Nâng cấp lên gói 1-file" upgrade button.
  - **State C (Bundle)**: Manages collaborators via `project.driveFileId`.
- Update the security banner text to accurately describe single bundle file storage and file-specific permission scoping.

### 3. `specs/072-drive-bundle-crdt-sync/tasks.md`
- Rectify Task T018 text to reflect explicit owner upgrade in `ShareProjectModal` instead of automatic background sync upgrade.

### 4. Tests
- Add tests for `ShareProjectModal.tsx` verifying:
  - Unshared project triggers `migrateOwnerProjectToBundle`.
  - Granular project loads collaborators via `driveFolderId` and shows manual upgrade option.
  - Bundle project loads collaborators via `driveFileId`.
- Update/expand `googleDrivePermissionsService.test.ts` to verify file ID and folder ID permission operations.
